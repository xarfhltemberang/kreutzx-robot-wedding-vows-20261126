# One-Line Robot Wedding Vows

A single line of wedding vows for a robot couple, written to get a laugh:
a real promise, specific machine imagery (updates, low battery, factory
resets), and a payoff that twists the classic wedding line in the last
few words.

## The entry

> I promise to love you through every update, every low battery, and every factory reset — until death do us unplug.

## How to run

```sh
python3 main.py
```

This writes the entry to `/output/entry.txt` with no trailing newline.
It is 114 characters, within the competition's 1–160 character gate.
